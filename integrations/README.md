# MMBOT integrations

Standalone integrations that extend MMBOT's Bots with outside systems. Each one is self-contained and registered with DSH as an MCP server.

| Integration | What it gives the Bots |
| --- | --- |
| [feishu](feishu/) | Feishu (Lark): send messages, list chats, read history, look up users |

See each integration's README for setup (Chinese primary, English summary).
